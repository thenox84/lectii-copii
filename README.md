# Orașul din Telefon 📱🏙️

Un joc-aventură educativ, în limba română, pentru **Andrei (10 ani)**, **Maria (6 ani)** și **Elena (2 ani)**.

Andrei face o poză cățelului și vrea să i-o trimită bunicii. Poza trece prin tot „orașul din telefon”, iar la fiecare clădire Andrei află, cu cuvinte simple, cum lucrează telefonul:

| # | Clădirea | Ce învață Andrei |
|---|----------|------------------|
| 1 | Studioul foto | o poză e un mozaic din pătrățele colorate (camera, pixelii) |
| 2 | Fabrica de numere | fiecare culoare devine un număr (procesorul) |
| 3 | Masa de lucru și Dulapul | ce se pierde și ce rămâne când se stinge telefonul (memoria) |
| 4 | Centrala electrică | bateria se golește și se încarcă |
| 5 | Poșta | poza intră într-un plic cu adresa bunicii (aplicația de mesaje) |
| 6 | Aeroportul | plicul zboară prin aer și prin cabluri până la bunica ✓✓ (antena) |
| 7 | Primăria | parola e secretă; poze trimitem doar oamenilor cunoscuți (siguranța) |
| 8 | Sala de concerte | sunetul, microfonul și difuzorul — cu pian virtual și înregistrare la pianul adevărat |

**Pentru Maria:** în fiecare clădire e ascunsă o fundiță roz 🎀 cu o misiune (numărat, potrivit culori, găsit steluțe, „Pianul Mariei”). Butonul 🔊 citește cerința cu voce. Steluțele se adună în borcanul de pe hartă.

**Pentru Elena:** iepurașul ei se ascunde în fiecare clădire; pe hartă, soarele, norii, copacii, cățelul și pisica reacționează la atingere; butonul mare **„Joaca Elenei”** deschide un ecran fără reguli, cu animăluțe, baloane și confetti.

La final, bunica răspunde la mesaj și se pot tipări **trei diplome**.

## Cum se joacă

Deschideți linkul jocului în browser (Chrome, Safari, Edge sau Firefox), pe tabletă, telefon sau calculator. Nu trebuie instalat nimic. Progresul se salvează automat în browserul folosit.

Pe tabletă sau telefon puteți adăuga jocul pe ecranul principal: în Safari, butonul „Partajează” → „Adaugă pe ecranul principal”; în Chrome, meniul ⋮ → „Adaugă pe ecranul de pornire”.

## Pentru părinți

- Butonul ⚙️ de pe hartă: sunet, voce, deschiderea tuturor clădirilor, diplomele, ștergerea progresului.
- **Joaca Elenei** se închide ținând apăsat ~1 secundă butonul mic ✕ din colțul din dreapta-sus.
- **Microfonul** (înregistrarea la pian) se folosește doar dacă dați voie. Înregistrarea rămâne numai pe acel dispozitiv. Dacă refuzați, restul jocului merge normal.
- **Vocea** folosește vocile instalate pe dispozitiv. Dacă nu există o voce românească, o puteți adăuga: pe iPhone/iPad din Setări → Accesibilitate → Conținut vorbit → Voci → Română.
- Pe iPhone, dacă nu se aude nimic, verificați butonul de „silențios”.
- Melodiile recunoscute de pianul virtual sunt doar piese vechi, libere de drepturi de autor: începutul din *Rondo alla Turca* (Mozart), începutul *Preludiului în Do major* (Bach) și „Steluța” (*Ah! vous dirai-je, maman*, melodie populară franceză).

## Tehnic

Doar HTML, CSS și JavaScript, fără server și fără biblioteci externe. Toate desenele sunt SVG desenate în cod; sunetele sunt făcute cu Web Audio API, vocea cu Web Speech API. Se publică pe GitHub Pages direct din fișierele acestui depozit.
